# orbit

(READMEはAI generatedです…あとで整理します)

**orbit** は、すべての描画操作を「イベントログ」として記録する、軽量なテキストベースのホワイトボードアプリケーションです。

単に画像を保存するのではなく、描画のプロセスそのものを **.wbel** (Whiteboard Event Log) という独自形式で保存・復元できるのが最大の特徴です。

---

## ✨ 特徴

### **イベントソーシング・アーキテクチャ**
* すべての「描いた」「消した」「戻した」という操作をログとして保持。
* 過去の操作履歴を完全に再現可能です。


### **テキスト形式のデータ保存 (.wbel)**
* 描画データを画像ではなくテキストで管理するため、ファイルサイズが極めて軽量です。
* メモ帳などで中身を確認・編集することも可能です。


### **インポート / エクスポート**
* 作業状態をファイルとして保存し、いつでも再開できます。


### **高度な描画ロジック**
* **ベジェ曲線**: 描いた線を滑らかな曲線に自動変換します。
* **高速な当たり判定**: Bounding Box（境界ボックス）計算により、大量の線があっても消しゴム操作がスムーズです。


### **多彩なツール**
* ✏️ **ペン**: 色と太さを自由にカスタマイズ可能。
* 🧹 **消しゴム**: 線を一本ずつピンポイントで削除。
* 🔲 **範囲削除**: 矩形選択した範囲内の線を一括で削除。



---

## 🚀 使い方

1. `index.html` をブラウザで開きます。
2. ツールバーからペン、消しゴム、または範囲削除を選択して操作します。
3. **保存**: 「💾 エクスポート」をクリックすると、`.wbel` ファイルがダウンロードされます。
4. **読み込み**: 「📁 インポート」をクリックして保存済みの `.wbel` ファイルを選択すると、描画が復元されます。

## 📄 データフォーマット (.wbel)

`.wbel` ファイルは、カンマ区切りのプレーンテキスト形式です。

| タイプ | 内容 |
| --- | --- |
| **D (Draw)** | 描画イベント（ID, 色, 太さ, BBox座標, パスデータ） |
| **E (Erase)** | 消去イベント（削除対象のIDリスト） |
| **U (Undo)** | 取り消しイベント（直前の操作をキャンセル） |

**例:**

```text
D,2026-02-15T13:50:00.000Z,s:1a2b3c,#000000,5,10,10,100,100,M 10 10 Q 50 50 100 100 L 100 100
D,2026-02-15T13:50:05.000Z,s:4d5e6f,#ff0000,10,200,200,300,300,M 200 200 Q 250 250 300 300 L 300 300
E,2026-02-15T13:50:15.000Z,s:1a2b3c
U,2026-02-15T13:50:20.000Z
E,2026-02-15T13:50:25.000Z,s:1a2b3c;s:4d5e6f
```
